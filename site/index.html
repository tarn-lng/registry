dbus 0.1.0

Independent Linux D-Bus client and signal library backed by libdbus-1. Explicit native linking required. No server objects or desktop widget API yet.

Release record · Source and documentation

Install

tarn add dbus --registry https://tarn-lng.github.io/registry/
tarn build --link dbus-1

Hashes verify integrity, not publisher trust. Signed provenance and authenticated CLI publication are not implemented.
